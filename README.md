# 📇 Contacts Management System (C# WinForms – 3-Tier Architecture)
## 📖 About the Project
A Windows Forms desktop application for managing contacts, built using C# and a clean 3-tier architecture.
The system allows users to add, edit, delete, and view contacts, with full integration to SQL Server, Countries, and optional contact images.
This project is part of the Abu-Hadhoud Platform training track with Dr. Muhammed Abu-Hadhoud.
It is also the extension / WinForms Presentation Layer of https://github.com/Hamani-Mohamed/Project-10-Learning-3-Tier-Architechture and https://github.com/Hamani-Mohamed/Project-11-Contacts-Extension

## 📌 Features

📋 View all contacts in a DataGridView

➕ Add new contacts

✏️ Edit existing contacts

❌ Delete contacts with confirmation

🌍 Assign a country to each contact

🖼️ Add / remove contact images

🔄 Automatic refresh after changes

🧱 Clean separation of Presentation, Business, and Data Access layers
